# Table of Contents Components

Components for the right-rail TOC. In the SSG, TOC entries are auto-generated from document headings (level 1 and level 2 sections).

---

## TableOfContents

Renders `<div class="toc">` with an "In this entry" label and a numbered `<ol>`. Roman-numeral prefixes are generated by `codex.css` via CSS counter — no numbers appear in markup.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `ChildContent` | `RenderFragment` | Yes | `HeaderLink` entries |

```razor
<TableOfContents>
    <HeaderLink Value="Religion" Href="religion" />
    <HeaderLink Value="Cultural" Href="cultural" />
</TableOfContents>
```

---

## HeaderLink

A single `<li><a>` in the TOC. Uses `NavigationManager` to build the full in-page anchor from the base URI.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `Value` | `string` | Yes | Display text |
| `Href` | `string` | Yes | Anchor id (without `#`); must match the `id` on the corresponding `h2.section` or `h3.sub` |

> **Note:** In the SSG context, `NavigationManager` is provided by `SsgNavigationManager` which returns the configured base href. The computed link becomes `{baseHref}#{Href}`.
