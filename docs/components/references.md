# Reference Components

Components for the footnote section at the bottom of an article. In `.athena` documents, footnote definitions (`[^key]: text`) are automatically collected by the parser and rendered here. Inline footnote references (`[^key]`) in the article body are stripped during rendering — the definitions in this section are the canonical source.

---

## ReferenceSection

Renders `<div class="refs">` with a "References" heading and a two-column `<ol>`. Roman-numeral counters are applied by `codex.css` via CSS counter.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `ChildContent` | `RenderFragment` | Yes | `ReferenceLink` items |

```razor
<ReferenceSection>
    <ReferenceLink>/'ɛɾbɑd'/ — Herbad: Aenarian word for priest.</ReferenceLink>
</ReferenceSection>
```

---

## ReferenceLink

A single `<li>` in the reference list. The roman-numeral prefix is generated by CSS; no explicit number is rendered in markup.

The `Href` parameter is retained for API compatibility but not rendered — references are plain text, not hyperlinks.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `ChildContent` | `RenderFragment` | Yes | Citation text (IPA transcription, source title, etc.) |
| `Href` | `string` | No | Unused; kept for API compatibility |
